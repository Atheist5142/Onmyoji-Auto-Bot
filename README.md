# Onmyoji Auto Bot

Tool tự động hóa Onmyoji trên Windows.

## Chạy bằng Python

```powershell
python -m pip install -r requirements.txt
python main.py
```

Mở game trước khi bấm **BẮT ĐẦU**. Task mặc định là **Realm Raid**.

## Bản `.exe`

Vào tab **Actions** trên GitHub để tải artifact build mới nhất.

Giữ nguyên toàn bộ thư mục sau khi tải, sau đó chạy:

```text
OnmyojiAutoBot.exe
```

Không xóa thư mục `templates`.

## Sử dụng

- **BẮT ĐẦU**: chạy task đã chọn.
- **DỪNG**: dừng tool và hiện lại game.
- **Ẩn game**: đưa game ra ngoài màn hình nhưng không minimize.
- **Hiện game**: đưa game về vị trí cũ.
- **Cập nhật**: kiểm tra phiên bản mới trên GitHub Releases.

## Task hiện có

- Realm Raid
- Farm Souls
